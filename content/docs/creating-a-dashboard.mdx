---
title: Creating a Dashboard
description: Define what the dashboard is, who it's for, and which lending product it serves.
---

From the Dashboards list, click **+ CREATE DASHBOARD** (top right). This opens a
form where you define what the dashboard is and who it's for:

<Screenshot
  src="SS-01.jpg"
  alt="The Create Dashboard form with type, client, name, product and description fields"
  caption="Creating the Test Dashboard for ABC EL."
/>

You'll fill in:

- **Dashboard Type**: the kind of dashboard you're building. There are two:
  - **Lender Dashboard**: tied to one specific client/lender.
  - **Platform Dashboard**: not tied to a single client; used across the
    platform.
- **Client Name**: the client this dashboard belongs to (for a Lender
  Dashboard). Pick the client first, since it drives the options below.
- **Dashboard Name**: the name shown back in the Dashboards list. Make it
  recognizable (e.g. `Test Dashboard`).
- **Product / Sub-Product**: auto-filled based on the client you selected; they
  identify which lending product this dashboard serves.
- **Description**: optional free-text notes about the dashboard's purpose.

For our example: Type = **Lender Dashboard**, Client = **Aditya Birla Capital -
Education Loans (ABC EL)**, Name = **Test Dashboard**. Click **Submit** to
create it.
