---
title: Creating a Component
description: Add a reusable block you can place inside any tab.
---

Switch the Layers Panel to **Components**, then click the `+` next to the
Component dropdown. This opens **Add New Component**:

<Screenshot
  src="SS-07.jpg"
  alt="The Add New Component modal with component level and name fields"
  caption="Adding a top-level component."
/>

## What are you creating?

- **Top-level component**: appears in the main components list, ready to be
  reused inside any tab.
- **Sub-component**: nested inside an existing top-level component, for building
  a smaller reusable piece within a bigger one.

Unlike tabs, components don't have a "product config" option, you always type a
**Component Name** yourself. That's because a component is never a standalone
page tied to the product's routing; it only ever exists as a block placed inside
tabs, so there's nothing for the system to predefine.

Pick **Top-level component**, name it something reusable (e.g. `Applicant
Info`), and click **Add Component**.
