---
title: Cloning a Dashboard
description: Copy an existing dashboard under a new name and client instead of rebuilding it.
---

**Cloning** makes a full copy of an existing dashboard under a new name and
client. It's the fastest way to reuse work: instead of rebuilding tabs, sections,
and fields from scratch for a similar client or product, you clone one that's
already built and adjust the copy.

## When to use it

- You've built a dashboard for one client and need a very similar one for another
  client.
- You want to try changes on a copy without touching the original.

## How to clone

Cloning starts from the **Dashboards list** (the screen you land on after login),
not from inside the builder.

1. Find the dashboard you want to copy in the list.
2. Click its **Actions** menu (the **⋮** on the right of that row).
3. Choose **Clone**.

This opens the **Clone Dashboard** popup. Fill in:

- **New Dashboard Name**: the name for the copy. Give it something that tells it
  apart from the original.
- **Select Client**: the client the copy belongs to. You can search the list.
  Choosing a different client here is what lets you reuse the same design for
  another client.

Both are required, the **Clone** button stays disabled until you've entered a
name and picked a client.

Click **Clone**. Dashforge creates the copy and it appears in the Dashboards list
as a new **Draft**, with everything from the original carried over.

## After cloning

The clone is independent of the original, edits to one don't affect the other.
Open the new dashboard from the list (via **Edit**) to adjust it, then Save and
Publish as usual.

<Callout>
The clone starts as a **Draft**. Nothing is live until you publish it, see
[Preview and Publish](/docs/preview-and-publish).
</Callout>
