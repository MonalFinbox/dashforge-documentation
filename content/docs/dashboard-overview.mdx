After you submit, Dashforge creates the dashboard and drops you on its
**overview page**, the home base for everything you'll configure on it.

At the top is a summary of what you just created, **Client**, **Type**,
**Created by**, and **Status**. The status stays `INACTIVE` until you publish
the dashboard, so this is a quick way to see whether it's live yet.

## Dashboard Modules

Below that are the **Dashboard Modules**, four separate building blocks, each
responsible for a different part of how the dashboard behaves. You open and
configure them one at a time:

- **UI Builder**: builds the actual interface: the tabs, sections, fields, and
  buttons users see and interact with. **This is what the rest of the guide
  covers.**
- **Policy Builder**: the rules, conditions, and overrides that govern how the
  dashboard behaves (e.g. what's allowed in a given loan state).
- **Task Builder**: tasks and triggers that fire when a user does something
  inside the dashboard.
- **Workflow Builder**: the workflow stages an application moves through.

Click the **UI Builder** card (or the **UI Builder** link in the left sidebar)
to start building the interface.
